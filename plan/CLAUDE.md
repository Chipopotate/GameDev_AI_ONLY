# CLAUDE.md — инструкции для ИИ-агента

Проект: 2D рогалик + автоматизация + защита базы на **pygame-ce** (рабочее название «Свет»).
Автор говорит по-русски: общайся с ним по-русски. Код и идентификаторы пиши по-английски, комментарии можно по-русски.

## Как работать

1. Прочитай `docs/00_overview.md`, затем только те документы, которые нужны текущему этапу из `docs/08_roadmap.md`. Не читай всё подряд.
2. Работай **одним этапом за раз**. Этап готов, когда выполнены его критерии приёмки и тесты проходят.
3. Не добавляй механик, которых нет в документах. Если нужна новая система, предложи её автору текстом и жди ответа.
4. Пункты со статусом ❓ (открытый вопрос) не решай сам: спроси автора или реализуй самый простой вариант за флагом в `config.py` и сообщи об этом.
5. Пункты 💡 не реализуй без явной просьбы.
6. Когда решение меняется, обнови соответствующий документ и добавь строку в `docs/00_overview.md` → Changelog.

Статусы: ✅ решено, ❓ открыто, 💡 идея на будущее, 🔧 число для настройки (в `config.py`/`data/`, не хардкодить).

## Стек и правила

- Python 3.11+, `pygame-ce`, `numpy`, `pytest`. Больше зависимостей не добавлять без согласования.
- **Никаких внешних ассетов.** Вся графика рисуется примитивами (`pygame.draw`) и процедурно, см. `docs/07_pygame_guide.md`. Звук на первых этапах не делаем.
- **Симуляция отдельно от отрисовки.** Папка `src/game/sim/` не импортирует `pygame`. Рендер только читает состояние симуляции. Это нужно для тестов без окна и для паузы.
- Весь рандом через экземпляр `random.Random(seed)`, который передаётся явно. Глобальный `random` в симуляции запрещён.
- Числа баланса только в `src/game/config.py` и `data/*.py`. Типы врагов, модулей, зданий, рецептов описываются данными, а не отдельными классами на каждый тип.
- Простота важнее красоты: обычные классы и dataclass, без ECS и сложных паттернов.

## Структура проекта

```
main.py
CLAUDE.md
docs/
src/game/
  config.py            # все числа баланса
  data/                # описания врагов, модулей, зданий, свойств (dict/dataclass)
  sim/                 # логика без pygame
    world.py           # тайлы, карта, генерация
    time_cycle.py      # день/ночь
    light.py           # свет и тьма
    resources.py       # свойства, рецепты, генератор забега
    buildings.py
    units.py           # дрон, роботы, корпуса и модули
    enemies.py
    pathing.py         # карта потока
    bases.py           # ростки, инкубаторы
    bosses.py
    meta.py            # мета-прогрессия
  render/              # отрисовка примитивами, камера
  ui/                  # HUD, книга рецептов, меню, управление
tests/
```

## Команды

```
pip install pygame-ce numpy pytest
python main.py
pytest -q
SDL_VIDEODRIVER=dummy python -m pytest -q   # тесты без окна
```

## Определение «готово» для любой задачи

- Игра запускается без ошибок и держит 60 FPS на карте стандартного размера (смотри счётчик FPS по F3).
- Тесты проходят. Для новой логики симуляции есть хотя бы один тест.
- Нет лишнего: не добавлено ничего вне задачи.
- Коротко отчитался автору: что сделано, что проверил, какие вопросы остались.
