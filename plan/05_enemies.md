# 05 — Враги

## Правило целей ✅ (основа ИИ, никакого сложного ИИ)
1. У каждого здания есть **приоритет**. У каждого типа врага своя таблица приоритетов (множители поверх базовых).
2. Враг выбирает цель по приоритету, с поправкой на расстояние (иначе побежит через всю карту ради одной турели).
3. К цели идёт по пути с **минимумом стен** (стена = дорогой тайл, не непроходимый).
4. Если пути без стен нет, бьёт стену, ближайшую к маршруту.
5. Слабые места рождаются сами: игрок закрывает проходы, и враги стягиваются в оставшийся.

Игроку правило объясняется одной строкой в обучении. 💡 Перед ночью тонкая линия показывает, куда пойдёт первая волна.

Реализация: см. `07_pygame_guide.md` (раздел «Карта потока»).

## Поля данных врага (`data/enemies.py`)
```python
EnemyType(
    id, name, tier,
    hp, speed, damage, attack_range, attack_cooldown,
    flying, ignores_walls,
    priorities={"turret": 8, "conveyor": 3, ...},   # множители целей
    spawn_source="dark_tile" | "incubator:walker" | ...,
    shape, color, size,           # для отрисовки примитивами
    special=None                  # id особого поведения, если есть
)
```
Особое поведение реализуется небольшим хуком `special`, а не отдельным классом на врага.

## Визуальный язык (примитивы)
Игрок и союзники: холодные цвета (циан, синий, белый). Враги: тёплые и ядовитые (маджента, оранжевый, токсично-зелёный, тёмно-красный). Форма говорит о роли: круг = масса, треугольник = атака, ромб = быстрый, шестиугольник = тяжёлый/дальний, крест = поддержка. Размер = опасность. Каждого врага должно быть возможно отличить за 0,3 с без чтения текста.

# Бестиарий

## Тир 1 (MVP, реализовать первыми) ✅

### 1. Тень (зомби)
- Роль: масса, фон. Спавнится на тёмных тайлах.
- Цели: ближайшее здание любого типа, тянется к дрону.
- Поведение: медленный, слабый, приходит поодиночке.
- Контрмера: свет (меньше тьмы, меньше теней).
- Вид: маленький тёмно-фиолетовый круг без контура, лёгкая пульсация.

### 2. Ходок
- Роль: основная масса волн из инкубатора.
- Цели: турели ×3, буры/сборщики ×2, стены ×0,5.
- Контрмера: турели с хорошим покрытием, продуманные стены.
- Вид: маджентовый треугольник, смотрит в сторону движения.

### 3. Москит
- Роль: давление на экономику, всегда есть работа по починке.
- Летает быстро, группами 3–6, обходит стены и наземную оборону.
- Цели: **конвейеры и провода ×10**, остальное игнорирует.
- Контрмера: ПВО-модули, ремонтные роботы, подземные/закрытые линии (если рецепт откроется).
- Читаемость: жёлто-зелёный, характерный высокий звук (если звук будет), след за ним.
- Вид: маленький жёлто-зелёный ромб с двумя тонкими линиями-крыльями.

### 4. Артиллерия
- Роль: стратегическая задача. Занимает позицию вдали, долго разрушает базу.
- Цели: самые дорогие постройки, радиус стрельбы больше, чем у турелей.
- Поведение: идёт в точку, «разворачивается» (несколько секунд, видна анимация), затем стреляет редко и сильно.
- Контрмера: отряд роботов для ответного удара, дальнобойный модуль.
- Вид: большой оранжевый шестиугольник, в развёрнутом состоянии вокруг тонкое кольцо радиуса.

## Тир 2 (идеи, 💡 после MVP; по умолчанию не реализовывать)

### 5. Таран
- Роль: наказывает слишком большую веру в лабиринт стен. **Исключение из правила «минимум стен»**: идёт почти по прямой к цели и ломает всё на пути.
- Медленный, толстая броня спереди, малое число.
- Контрмера: глубокая оборона слоями, тяжёлое оружие, ловушки.
- Вид: широкий тёмно-красный квадрат с острыми «зубами» спереди.

### 6. Заразитель
- Роль: бьёт по инфраструктуре света. Летит над лампами и «гасит» лампу в радиусе на 20 с 🔧.
- Цели: лампы ×10. Погасшая лампа → тьма → Тени.
- Контрмера: ПВО, резервные лампы, ремонт/перезапуск.
- Вид: тёмно-зелёная капля с мерцающим ореолом.

### 7. Вор
- Роль: бьёт по складам. Быстро бежит к складу/депо, хватает ресурсы и бежит к ближайшему ростку. **Если добежал, ресурсы идут в очки роста ростка.** Если убит, ресурсы выпадают, их можно подобрать.
- Цели: склад/депо ×10, конец конвейера с предметами ×6.
- Контрмера: охрана складов, быстрые турели у депо, патруль.
- Вид: оранжевый круг с маленьким квадратом-мешком.

### 8. Гончая
- Роль: охотится на логистику роботов. Игнорирует здания, выбирает **курьеров и снабженцев** (а затем дрона).
- Быстрая, хрупкая, приходит стаей.
- Контрмера: эскорт танков, патруль у маршрута.
- Вид: тонкий вытянутый красно-оранжевый овал.

### 9. Панцирник
- Роль: проверка разнообразия оружия. Щит спереди поглощает снаряды, уязвим с флангов и к урону по площади.
- Вид: круг с дугой впереди.

### 10. Лекарь
- Роль: лечит врагов вокруг, хрупкий, держится сзади. Главная цель для игрока.
- Контрмера: дальнобойный модуль, урон по площади.
- Вид: зелёный крест на маленьком круге.

### 11. Глушитель
- Роль: пульсирующее поле радиуса R 🔧 отключает модули роботов (радар, ремонт, передача боеприпасов) и скан дрона внутри. Стационарные турели не затрагивает.
- Контрмера: убить первым, держать робототехнику вне радиуса.
- Вид: тёмный круг с пульсирующим кольцом.

### 12. Мимик
- Роль: засада на ранней ручной фазе. Маскируется под залежь ресурса, неотличим на глаз. Когда дрон или робот ближе 2 тайлов, раскрывается и атакует. **Скан дроном выдаёт Мимика**, поэтому он усиливает ценность сканирования.
- Появляется только на заражённых/тёмных тайлах.
- Вид: как обычная залежь, но чуть нестабильный контур (при скане становится красным).

### 13. Делитель
- Роль: при смерти распадается на 2–3 малых. Награждает урон по площади.
- Вид: большой круг, внутри которого видны малые круги.

### 14. Спороносец ❓
- Альтернативная реализация возрождения ростка (вместо абстрактной задержки). При гибели ростка выпускается медленный летящий «споровый пузырь», который летит к тёмному тайлу и там сажает новый росток. **Если его сбить по дороге, росток не возрождается.** Игрок видит его заранее и может реагировать.
- Решает автор (открытый вопрос 8 в `00_overview.md`).
- Вид: полупрозрачный фиолетовый круг с тонкой линией-следом.

## Мутации ✅ идея, 💡 реализация после MVP
Каждый день (перед ночью) к случайному типу врага добавляется мутация, действует до конца забега. Примеры: бронированные, быстрые, регенерация, взрыв при смерти, дальняя атака, иммунитет к одному типу оружия. Число мутаций растёт быстрее на поздних планетах.
