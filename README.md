# Свет — прототип

2D рогалик + автоматизация + защита базы. Вид сверху, тайловая карта, вся графика —
примитивы, ни одного внешнего файла. Дизайн-документы: `plan/`.

**Текущий билд: M0 + M1 + M2 + M3 + M3.5 + M4 + M4.6** — случайная карта, камера, дрон, ручная
добыча, инвентарь на слотах и контейнерах, пауза, смена дня и ночи, лампы, тьма и счётчик
освещённости, генератор забега (свойства, имена, значки), скан свойств, лаборатория, реликвии и
крафт по свойствам, **экономика**: восемь зданий (лампа, лаборатория, бур, конвейер, провод, склад,
сборщик, генератор), сеть энергии с генератором на топливе, работающая сама линия «бур → конвейер →
склад» и сборщик, собирающий предметы ролей по рецепту. С **M4.6** постройка — это **предмет**:
её крафтят в окне инвентаря (**E**, панель крафта справа от сетки) и ставят **ПКМ** из **хотбара**
внизу экрана, видя под курсором зелёный или красный призрак; разбирают удержанием ЛКМ, и она падает
на землю предметом. У действий дрона есть луч: красный — добыча и разбор, синий — изучение и скан.

![ночь](screenshots/m2_lamps_night.png)

*Ночь: лампа освещает круг, остальное скрыто тьмой. Без ламп (`py main.py --night`) — `screenshots/m2_night.png`.*

## Запуск

**Проще всего — двойной клик по `run_game.bat`.** Он сам найдёт Python, при первом запуске
поставит зависимости и откроет игру. Ключи тоже работают: `run_game.bat --seed 42`.

Вручную:

```bash
py -m pip install -r requirements.txt
py main.py
```

> На этой машине `python` в PATH — заглушка Microsoft Store, поэтому используется `py`.
> Если `python` у вас работает, команды те же.

Полезные ключи:

```bash
py main.py --seed 42                      # воспроизводимая карта
py main.py --fullscreen
py main.py --night                           # отладка: начать сразу с ночи
py main.py --headless --screenshot out.png   # кадр без окна
py main.py --headless --bench 300            # замер FPS
```

## Управление

Единственный источник — [`plan/10_controls.md`](plan/10_controls.md): та же таблица лежит в коде
(`src/game/ui/controls.py`), из неё рисуется подсказка в игре, а тест сверяет их построчно. Ниже —
копия.

| Клавиша | Действие |
|---|---|
| WASD | движение дрона |
| 1–9 / ЛКМ по слоту | выбор слота хотбара; Shift+колесо листает |
| ПКМ по пустому тайлу | поставить постройку из выбранного слота; пустой слот: ничего |
| ПКМ (удерж.) по залежи, слот не с постройкой | скан свойств |
| ЛКМ (удерж.) по залежи | добыча |
| ЛКМ (удерж.) по реликвии | изучение |
| ЛКМ (удерж.) по своей постройке | повреждённую — чинить; целую — разобрать (падает на землю предметом) |
| ПКМ по зданию с контейнерами | окно его контейнеров |
| ЛКМ по роботу (Shift — добавить) | выбрать робота |
| ПКМ с выбранными роботами | охранять точку / атаковать врага; Shift — в очередь |
| F / P (роботы выбраны) | за дроном / патруль до точки под курсором |
| Ctrl+1–9 / Alt+1–9 | назначить группу / выбрать группу роботов |
| R | повернуть призрак / конвейер под курсором |
| E | инвентарь + крафт |
| в окне: ЛКМ/ПКМ/Shift/двойной клик/Q | как в M3.5 |
| Пробел | пауза |
| Колесо | зум 0.5×…2× |
| F1 | поле пути врагов |
| F2 | слой света |
| F3 | отладочная панель |
| F4 | галерея графики |
| Esc | снять фокус поиска / закрыть окно / снять выбор роботов / меню паузы |

В окне (как в M3.5): ЛКМ по слоту — взять стак «в руку» или положить (такой же предмет
досыпается до лимита, другой меняется местами), ПКМ — взять половину или положить одну единицу,
Shift+ЛКМ — перекинуть стак в соседнюю сетку (в окне E — между инвентарём и хотбаром), двойной
ЛКМ — собрать в руку весь этот предмет, Q — выбросить стак из-под курсора, «Сортировать» —
разложить сетку дрона. В панели крафта: клик — 1, Shift+клик — ×5, Ctrl+клик — максимум. Пока поле
поиска в фокусе, клавиши идут в него (WASD, цифры, E, R не действуют); Esc сначала снимает фокус,
второй Esc закрывает окно.

Мелкие правила из `plan/10` (раздел «Уточнения»): ПКМ по красному призраку или по зданию без
контейнеров — ничего, даже без сообщения; над хотбаром и панелями HUD нет призрака, а клики и
удержания не уходят в мир; нажатие, потраченное на интерфейс или постановку, до отпускания не
становится удержанием (ПКМ, поставившая последний бур, не начинает скан его залежи, ЛКМ со слота
хотбара не копает); с лампой или другой постройкой без направления в слоте R ничего не делает;
пауза видна и поверх открытого окна.

## Что уже работает

- Случайная карта 96×96 из земли, гор и воды; стартовая зона 30×30 замкнута горным кольцом.
- Генератор **гарантирует**: старт герметичен, а вся земля снаружи кольца — одна связная область
  (между карманами прорубаются узкие проходы). Проверено обходом в ширину на 200 сидах.
- **Генератор забега**: 8 природных ресурсов + 1 редкий, у обычного 1–2 свойства, у редкого 3.
  Свойства, имя (из слогов), форма и цвет значка **разные в каждом забеге** — постоянны только роли
  и правила. Уникальность имён, значков и наборов свойств проверена тестом на разных сидах.
- **Гарантия проходимости**: у каждого свойства и каждой роли есть источник среди ресурсов
  стартовой зоны, иначе генератор выдаёт недостающее свойство одному из ресурсов. Проверено
  на 1000 сидах (`pytest -m slow`).
- Редкий ресурс — одно месторождение на 30 единиц: он закрывает сразу несколько слотов рецептов.
- Дрон ходит, скользит вдоль стен, не проходит горы и воду.
- Ручная добыча: подойди к залежи, наведи на неё курсор и держи ЛКМ. Добывается именно та
  залежь, на которую смотришь, а не «ближайшая». Залежь истощается и уменьшается на глазах.
- **Смена дня и ночи** по таблице планеты: первый день 360 с, дальше день 180 с и ночь 45 с.
  Смена фазы сообщается в HUD и всплывающим сообщением.
- **Тьма**: ночью карта затемняется, мягкий край — бесплатно от `smoothscale`. Темнота —
  это «не освещено», отдельного слоя нет. Собственный свет дрона вырезает небольшое пятно,
  чтобы игрок видел себя, но для победы он не считается (`plan/01`).
- **Источники света различаются цветом**: лампа светит тёплым жёлтым, дрон — холодным
  синеватым. Пятна рисуются аддитивно поверх тьмы (тьма умеет только затемнять), поэтому
  по одному взгляду видно, что засчитано в «% освещено», а что даёт личный фонарь дрона.
- **Лампы**: предмет «Лампа» из хотбара, ПКМ по земле рядом с дроном ставит её, удержание ЛКМ —
  разбирает. Лампа освещает круг радиусом 7 тайлов. С M4 лампа — **здание**, и горит она, только
  пока её питает сеть: поставили — сеть зажгла её на ближайшем шаге, кончилось топливо —
  погасла. Слой света пересчитывается только когда лампа появилась, исчезла, включилась или
  выключилась — это проверено тестом.
- **Счётчик «освещено»** — доля освещённых доступных тайлов (доступные = проходимая земля,
  связанная со стартом; сейчас это стартовая зона).
- **Изучение свойств.** Первый подбор ресурса показывает одно его свойство и сообщает об этом,
  остальные стоят как `?`. Скан (удержание ПКМ, когда в слоте не постройка, 0.8 с, нужна
  близость) открывает ещё одно, лаборатория — все сразу. Слотов свойств ровно столько, сколько
  свойств у ресурса.
- **Реликвии** лежат на карте: базовые (по одной на роль) открывают базовый рецепт роли **и рецепты
  построек этой роли** (автоматика — бур, конвейер, провод, сборщик; конструкционный материал —
  склад; энергия — генератор), усилители — более выгодный вариант той же роли. Изучение — ЛКМ по
  реликвии, 2.5 с: пока держишь, видно полосу и синий луч.
- **Лаборатория** (предмет из хотбара, рецепт известен с начала): ставится рядом с дроном.
  Подошёл, ПКМ — открылось окно слотов: слева 🔧 2 слота под образцы, справа инвентарь дрона,
  ресурсы перекладываются мышью. Образец
  анализируется **сам, без кнопок**, и каждый слот считает свой прогресс: 🔧 10 с на образец,
  тратится 🔧 1 единица. Под сеткой видно состояние каждого слота — «пусто», «анализ 40%» с
  полосой, «изучено», «нет энергии». Анализ идёт в симуляции, поэтому продолжается и с закрытым
  окном, и когда дрон ушёл по делам (пауза его останавливает). По окончании открываются **все**
  свойства ресурса. Ресурс с уже открытыми свойствами лаборатория не трогает: слот показывает
  «изучено», а образец остаётся лежать.
- **Инвентарь дрона — слоты, как в Minecraft**: 🔧 20 слотов по 🔧 30 единиц (клавиша **E**).
  Инвентарь не бездонный: когда места нет, добыча останавливается с сообщением (луча и подсказки
  «Добываю» тогда нет), а крафт отказывается работать, если результат некуда положить.
- **Хотбар** — 🔧 9 слотов внизу по центру экрана, виден всегда, и поверх окон тоже. Слот выбирают
  клавиши 1–9, ЛКМ по нему или Shift+колесо. Это отдельный контейнер дрона с одним правилом:
  предмет-постройка ложится сначала в хотбар (в такой же стак или в пустой слот), потом в
  инвентарь, а ресурс — в инвентарь и только досыпается в уже лежащие в хотбаре стаки, пустые слоты
  он не занимает. В окне E хотбар — ряд под сеткой инвентаря.
- **Постройки — предметы.** Восемь предметов-построек (значок — спрайт здания, стак 🔧 16)
  крафтятся по свойствам, как всё остальное: лампа ✨×2, лаборатория ✨×2 + 🪨×2, бур ⚙️×3 + 🪨×2,
  конвейер ⚡×2, провод ⚡×1, склад 🪨×4, сборщик ⚡×3 + 🪨×3, генератор 🔥×3 + ⚡×2 (🔧 цены в
  `data/buildings.py`). Лампа и лаборатория известны с начала забега, их свойства на каждом сиде
  есть у ресурсов стартовой зоны (проверено на 1000 сидах).
- **Постановка**: выбрал слот с постройкой — под курсором полупрозрачный **призрак** здания, зелёный
  (можно) или красный (занято, вне 🔧 6 тайлов `BUILD_RANGE`, горы или вода, залежь — для всех,
  кроме бура; бур — наоборот, только на залежь), с рамкой тайла и тусклым кольцом радиуса вокруг
  дрона (рамка тайла — поверх силуэта, кольцо — точного радиуса). ПКМ ставит здание и тратит
  ровно один предмет; ПКМ по красному призраку — ничего: ни постройки, ни сообщения. Призрак и
  постановка спрашивают одну и ту же проверку в симуляции. Предметы на земле не мешают:
  они остаются лежать под зданием и подбираются, когда дрон пройдёт рядом. Конвейер смотрит «от
  дрона», R поворачивает призрак, а без призрака — стоящий конвейер под курсором (с лампой или
  другой постройкой без направления в слоте R ничего не делает).
- **Луч дрона**: пока держишь действие, от дрона к цели идёт луч — красный переливающийся при
  добыче и разборе (искры и пятно в точке попадания), синий полупрозрачный при изучении и скане
  (поток точек к дрону, кольцо-сканер). Виден и ночью, на паузе замирает.
- **Выбросить и подобрать**: Q выбрасывает стак из слота под курсором — он падает на карту
  перед дроном. Упавшее лежит **на тайле** и **не исчезает** (🔧 `DROP_DESPAWN_SECONDS = None`):
  кучи одного ресурса на тайле сливаются, разные рисуются со сдвигом, чтобы обе были видны.
  Подойдя на 🔧 1.5 тайла (и через полсекунды после броска), дрон забирает столько, сколько
  влезло; что не влезло — остаётся лежать (сообщение о полном инвентаре — одно, а не по кадру).
- **Разбор здания**: удержание ЛКМ по своей постройке в радиусе 🔧 6 тайлов, 🔧 0.7 с с кольцом
  прогресса и красным лучом. Отпустил раньше — прогресс сброшен, здание стоит. Готово — сообщение
  «Разобрано: имя», короткая вспышка и дымок (осколки и тряска экрана — только у разрушения),
  здание исчезает, на его тайле лежит **предмет-постройка**, а содержимое **всех** его контейнеров
  высыпается на свободные тайлы вокруг, по стаку на тайл (если места нет — на тайл самого здания).
  Сколько лежало в здании, столько и окажется на земле (закон сохранения под тестом). Дрон
  подбирает всё обычным автоподбором; при полном инвентаре вещи просто ждут на земле.
- **Экономика (M4)**: восемь зданий одной таблицей в данных — лампа, лаборатория, бур, конвейер,
  провод, склад, сборщик, генератор. С M4.6 здание стоит ровно один свой предмет-постройку (цены
  в предметах ролей больше нет). Бур ставится **на** залежь, остальные — на свободную землю.
- **Работа идёт сама**, без кнопок: **бур** 🔧 добывает из залежи под собой (1.2 с на единицу),
  **конвейер** 🔧 0.35 с перекладывает предмет «сначала вперёд, потом из-за спины» — так линия
  собирается сама, а когда она забьётся, бур просто встанет; **сборщик** собирает предмет роли по
  выбранному рецепту за `Recipe.craft_time`, беря материалы со входа по свойствам (кнопка «Рецепт»
  перебирает все изученные рецепты ролей, усилители тоже);
  **генератор** жжёт топливо. Поэтому приёмка «бур → конвейер → склад» — это три здания и один
  генератор, поставленные рядом: дальше они работают без игрока.
- **Сеть энергии** (`sim/power.py`): сеть — это точки на **соседних тайлах** (4 стороны), а
  **провод** — такое же здание, которое ничего не даёт и не тратит, а только тянет сеть через
  пустое место. Правило грубое и понятное: сеть работает, если выработка генераторов **не меньше**
  спроса потребителей; энергия не накапливается, избыток пропадает. Потребителя без энергии
  видно сразу: лампа гаснет, бур стоит, слот лаборатории пишет «нет энергии», сборщик не начинает.
- **Топливо**: генератор жжёт единицу топлива 🔧 20 с, и топливом считается и сырьё со свойством
  🔥, и крафченый предмет «энергия». Тратит он его **только пока его сети есть что питать** —
  иначе выжигал бы склад впустую. Обратная сторона этого порядка — энергия появляется на
  следующем шаге после того, как топка загорелась.
- **Панель крафта** в окне E (книги рецептов больше нет): вверху поиск по названию (без учёта
  регистра, «×» очищает), ниже **только изученные** рецепты — никаких «???», подсказок и счётчиков
  неоткрытого. Доступный сейчас рецепт яркий, недостающий приглушён, сначала доступные, затем по
  названию. Тултип: название, результат и «свойство ×N (есть M)», где M считается только по уже
  открытым свойствам. Клик — 1, Shift — ×5, Ctrl — максимум; крафт мгновенный, не вышло — красная
  вспышка и сообщение. Крафт идёт **по свойствам**: подходит любой ресурс с нужным свойством, а
  ресурс с двумя нужными свойствами тратится один раз и закрывает сразу два слота.
- **Свечение**: неон построек, ореолы ламп и ядра генератора, огонь сопел дрона, искры и мягкий
  край пятна луча. До исправления в M4.6 все эти ореолы из-за ошибки (лишнее деление на 255 в
  `render/sprites/factory.py`) были чёрными и не светились; яркости пересняты по скриншотам.
- Всплывающие сообщения, пауза (видна и поверх окна), отладочные оверлеи F2/F3.

## Враги и оборона (M5)

- **Ночь опасна.** На закате из темноты выходят **Ходоки** (🔧 3 в первую ночь, +2 каждый день),
  а пока ночь идёт, во тьме рождаются **Тени** (тают на рассвете). Свет лампы — это место, где
  они не появляются.
- **Враги идут не напролом**: у каждого типа своё поле пути от целей (Ходок любит турели, буры и
  сборщики; Тень тянется к дрону). Стена — дорогой тайл, а не стена-непроходимость: пока есть
  обход, враги обходят; закрыл все проходы — ломают самое дешёвое место. **F1** показывает поле
  Ходоков: красное — куда стекаются враги.
- **Турель** (🪨×3 + 💥×2, открывает реликвия «Боеприпас») стреляет сама, тратит «Боеприпас» из
  своего контейнера (его можно положить руками или довезти конвейером). **Стена** — 🪨×1.
  У дрона слабое оружие: стреляет само по ближайшему врагу.
- **Потери:** здания и лампы ломаются, из разрушенного выпадает половина содержимого.
  **Поражение** — смерть дрона: экран показывает причину и **точку прорыва** (красное кольцо).
- По просьбе автора в залежах стало больше ресурса: 🔧 200 вместо 60.
- **M6:** с 3-го дня прилетают **москиты** — летят напрямую к конвейерам и проводам, наземные
  турели их не достают (бьёт оружие дрона). С 5-го дня приходит **артиллерия**: разворачивается
  (кольцо дальности) и бьёт издалека по генераторам, сборщикам, лабораториям. **Ремонт:** держи
  ЛКМ на повреждённой своей постройке — дрон её чинит (зелёный луч); целую — разбирает.
- **Esc больше не закрывает игру:** он открывает меню паузы с кнопками «Продолжить», «Помощь»
  (таблица управления — в HUD её больше нет) и «Выйти».
- **Топливо всегда рядом:** у одного ресурса «горючий» виден с первого подбора, и его залежь лежит
  в 6 тайлах от старта — генератор можно построить на любом сиде.

## Роботы (M7)

- **Мастерская** (реликвия «Автоматика», нужна сеть): положи в её вход «Материал», «Автоматику»
  (и «Боеприпас» для бойца и снабженца), выбери робота кнопкой в окне — она соберёт его сама.
- **Боец** стреляет по врагам рядом, **Танк** принимает удары на себя, **Снабженец** берёт
  боеприпасы со склада и раздаёт бойцам и турелям, **Курьер** без приказа возит боеприпасы со
  склада туда, где их не хватает.
- **Приказы:** ЛКМ по роботу — выбрать (Shift — добавить), ПКМ — охранять точку или атаковать
  врага под курсором (Shift — в очередь), F — за дроном, P — патруль до точки под курсором,
  Ctrl+1–9 — назначить группу, Alt+1–9 — выбрать её, Esc — снять выбор. Приказы работают и на паузе.

## Архитектура

```
main.py            CLI и точка входа
src/game/
  config.py        все числа баланса (ничего не хардкодится в других модулях)
  app.py           окно, главный цикл, ввод, пауза, фиксированный шаг симуляции
  data/            описания данных: тайлы, ресурсы, свойства, роли и рецепты, здания
  sim/             ЛОГИКА БЕЗ PYGAME: мир, генератор забега, дрон, слоты и контейнеры
                   (хотбар и правило «куда кладётся»), упавшие предметы, время суток, свет,
                   знание о свойствах и крафт, здания, сети энергии (`power.py`), работа
                   зданий, команды интерфейса (`commands.py`)
  render/          отрисовка примитивами: камера, формы, кэш чанков, значки, слои,
                   призрак постройки (`ghost.py`), луч дрона (`effects/laser.py`)
  ui/              HUD, хотбар, окно E (инвентарь + панель крафта) и окно здания, сетка
                   слотов, таблица управления, фокус ввода, отладка, виджеты, кэш шрифтов
tests/             pytest
```

Три правила, на которых всё держится:

1. **`sim/` не знает про pygame.** Логику можно тестировать без окна, а пауза — это просто
   «не вызывать `update`». Нарушение ловит `tests/test_architecture.py`.
2. **Данные, а не классы.** Тайлы и ресурсы описаны в `data/`; рендер умеет рисовать любую
   форму по имени из данных, поэтому новый ресурс — это одна строка в таблице.
3. **Фиксированный шаг.** Симуляция идёт шагами по 1/60 с, отрисовка отдельно.
   При `paused=True` состояние не меняется — это проверяется тестом.

Кэши, которые нельзя терять при доработке: чанки рельефа (`render/terrain_chunks.py`),
значки ресурсов (`render/icons.py`), шрифты и панели (`ui/`), слои поверх мира
(`render/overlay.py`). Карта рисуется один раз, дальше только блитится; пересчёт —
только через `invalidate_tile`. Слой света пересчитывается только при изменении ламп,
а тьма рисуется мелкой картинкой «пиксель на тайл» и растягивается на экран.

## Отклонения от дизайн-документов в этом билде

Это осознанные упрощения, а не забытые места:

- **Из стартовой зоны нельзя выйти.** По `plan/01` старт окружён горами, а обвал гор — этап M8.
  Залежи за кольцом видны, но недостижимы: это задел на будущее. Поэтому **редкое месторождение
  и базовые реликвии размещаются внутри стартовой зоны** — иначе забег был бы непроходим
  (усилители при этом честно лежат снаружи и пока недостижимы).
- **Лаборатория — постройка-предмет, ставится в 🔧 `BUILD_RANGE` = 6 тайлов от дрона и требует
  энергии** (флаги M3 `LAB_REQUIRES_POWER` и `LAB_PLACE_RANGE` сняты на M4, `LAB_RANGE` переименован
  в общий `CONTAINER_RANGE`). Образцы перекладываются в её слоты мышью в окне;
  окно закрывается само, если уйти от лаборатории — вместе с ним предмет из руки возвращается
  в контейнеры, а что не влезло, падает на землю.
- **Лаборатория больше не «пассивная»**: в `plan/02` было «образцы берутся в работу по одному»,
  в билде M3.5 каждый слот анализирует свой образец сам и параллельно (🔧 `LAB_ANALYZE_TIME` = 10 с).
  Кнопки «отправить образец» нет вовсе — образец кладут в слот, и анализ начинается сразу.
- **Скан свойств с M4 стоит энергии** (🔧 `SCAN_ENERGY_COST` = 2 предмета «энергия»), флаг
  `SCAN_REQUIRES_ENERGY` снят. Потребителей и генератор игрок ставит сам: без сети ресурсов
  не изучить.
- **Своего радиуса у лампы больше нет**: с M4.6 `LAMP_PLACE_RANGE` удалён, все постройки ставятся
  в общем 🔧 `BUILD_RANGE` = 6 тайлов.
- **Меню слота по ПКМ убрано.** ПКМ теперь берёт половину стака, а выбросить предмет можно
  клавишей **Q** по слоту под курсором (в меню из двух пунктов был смысл только для «выбросить»;
  «разделить пополам» делает ПКМ).
- **Полный инвентарь останавливает добычу** с сообщением, а не разбрасывает лишнее по карте
  (в Minecraft лишнее падает под ноги). Так сделано, чтобы дрон не мусорил без ведома игрока;
  вариант «выпадать из залежи» — на обсуждении.
- **Числа слотов временные** (🔧 20 слотов × 30 единиц у дрона, 🔧 2 слота у лаборатории):
  автор просил поставить их «на первое время», балансировка — на M5.
- **Цены и скорости работы — 🔧 догадки.** Рецепты предметов-построек (дешёвые намеренно:
  постройка — расходник), 🔧 1.2 с на единицу у бура, 🔧 0.35 с у конвейера,
  🔧 `GENERATOR_FUEL_TIME` = 20 с и мощность генератора 🔧 6 (`power_out` в `data/buildings.py`)
  поставлены «чтобы работало», а не из расчёта: балансировать их имеет смысл вместе с врагами
  (M5), иначе неясно, сколько времени игрок может себе позволить.
- **Цены построек — в `data/buildings.py`, а не в `config.py`**: рецепт — свойство конкретного
  здания, как и его HP (правило проекта разрешает числа баланса в `config.py` и `data/`).
- **`hp` и `enemy_priority` в данных есть, но не используются** — ломать здания пока некому,
  это M5. Пока здание не может быть разрушено, снос отдаёт всё содержимое
  (🔧 `DESTROY_DROP_RATIO = 1.0`).
- **Разобранная постройка падает на землю, а не в инвентарь** (так решено в дополнении к заданию
  M4.6): на тайле здания остаётся куча из одного предмета-постройки, а дрон подбирает её обычным
  автоподбором. Отпущенная раньше времени ЛКМ сбрасывает прогресс сразу (медленного отката нет).
  Поле `dismantlable` есть у всех зданий и пока везде `True`.
- **Предметы на земле под новым зданием остаются лежать**: постановка их не удаляет и не сдвигает,
  дрон подберёт их, пройдя рядом.
- **«Доступно» в панели крафта считается по знанию, а крафт — по настоящим свойствам** ❓. Яркость
  рецепта и «есть M» в тултипе видят только открытые свойства, чтобы панель не выдавала скрытое.
  Сам подбор материалов не менялся (так требовало задание), поэтому приглушённый рецепт может
  скрафтиться, если у ресурса нужное свойство есть, но ещё не открыто. Вопрос автору — в `plan/02`.
- **Предметы ролей «Материал» и «Автоматика» сейчас никуда не тратятся** ❓: в M4 они были ценой
  здания, а с M4.6 постройки крафтятся прямо из свойств. Вопрос автору — в `plan/02`.
- **Генератор со старта не известен** ❓: лампа и лаборатория открыты с начала, но лампа горит
  только от сети, а генератор открывает реликвия «Энергия». Она лежит в стартовой зоне, так что
  до первой ночи цепочка достижима. Вопрос автору — в `plan/02`.
- **Клавиши T, I, Tab, R-книга и 1–8 как режим стройки убраны** по заданию: поворот теперь на R,
  инвентарь — на E, крафт — в окне E, 1–9 выбирают слот хотбара.
- **R с постройкой без направления в слоте (лампа, склад…) ничего не делает** — даже над стоящим
  конвейером. Так буквально сказано в дополнении к заданию M4.6: конвейер под курсором крутится,
  «если призрака нет», а у лампы призрак есть.
- **Сканирующей линии при стройке и сносе** (`plan/09` § 10) пока нет. Постройка — кольцо-вспышка,
  разбор игроком — лёгкая вспышка и дымок, разрушение (на M5 — врагами) — мелкие осколки, дым и
  тряска экрана. У ламп (они живут в `sim/light.py`, а не среди зданий) вспышек нет вовсе.
- **Цена изучения реликвии оставлена ❓ за флагом** `RELIC_STUDY_COST = None` (`config.py`): в
  `plan/02` сказано «время/ресурс», но сколько — не решено, поэтому по умолчанию изучение, как и
  в M3, бесплатное. Код умеет и отказ («нечем платить»), и списание — включается одной строкой
  в `config.py`.
- **Свет дрона не считается для победы.** В `plan/01` это открытый вопрос ❓ с пометкой
  «по умолчанию нет» — так и сделано: свет дрона виден, но в счётчик «освещено» не входит.
