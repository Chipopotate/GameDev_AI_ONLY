# 10 — Управление (единый источник правды) ✅

Эта таблица — **единственный источник** управления. В коде она лежит в
`src/game/ui/controls.py` (`CONTROLS`), подсказка в игре (HUD, правый край над хотбаром; при
открытом окне скрыта) рисуется прямо из неё, а тест `tests/test_controls.py` сверяет таблицу
ниже с кодом построчно. Поменял управление — поменяй обе, иначе тест упадёт.

| Клавиша | Действие |
|---|---|
| WASD | движение дрона |
| 1–9 / ЛКМ по слоту | выбор слота хотбара; Shift+колесо листает |
| ПКМ по пустому тайлу | поставить постройку из выбранного слота; пустой слот: ничего |
| ПКМ (удерж.) по залежи, слот не с постройкой | скан свойств |
| ЛКМ (удерж.) по залежи | добыча |
| ЛКМ (удерж.) по реликвии | изучение |
| ЛКМ (удерж.) по своей постройке | повреждённую — чинить; целую — разобрать (падает на землю предметом) |
| ПКМ по зданию с контейнерами | окно его контейнеров |
| ЛКМ по роботу (Shift — добавить) | выбрать робота |
| ПКМ с выбранными роботами | охранять точку / атаковать врага; Shift — в очередь |
| F / P (роботы выбраны) | за дроном / патруль до точки под курсором |
| Ctrl+1–9 / Alt+1–9 | назначить группу / выбрать группу роботов |
| R | повернуть призрак / конвейер под курсором |
| E | инвентарь + крафт |
| в окне: ЛКМ/ПКМ/Shift/двойной клик/Q | как в M3.5 |
| Пробел | пауза |
| Колесо | зум 0.5×…2× |
| F1 | поле пути врагов |
| F2 | слой света |
| F3 | отладочная панель |
| F4 | галерея графики |
| Esc | снять фокус поиска / закрыть окно / снять выбор роботов / меню паузы («Продолжить», «Выйти») |

## Уточнения к таблице

- **Хотбар** (🔧 `HOTBAR_SLOTS = 9`) виден всегда внизу по центру, в том числе поверх окон.
  Слот: значок, число стака, цифра-подсказка 1–9, подсветка выбранного, подпись с именем при
  наведении. Колесо без Shift — зум. Shift+колесо листает слоты и тогда, когда система с Shift
  превращает прокрутку в горизонтальную (macOS, тачпады): шаг берётся из вертикали или горизонтали.
- **ПКМ по карте**, по порядку:
  1. здание с контейнерами под курсором — открыть его окно, **что бы ни было в слоте**
     (дрон должен быть в 🔧 `CONTAINER_RANGE`, иначе тост «Слишком далеко до здания»);
  2. в выбранном слоте постройка и призрак зелёный — поставить её на тайл (тратится ровно 1
     предмет);
  3. иначе — **ничего**: ни команды, ни тоста. Это красный призрак (занято, вне радиуса,
     неподходящий тайл — например, залежь под всё, кроме бура), здание без контейнеров, пустой
     слот или не постройка в нём (например, ресурс).
- **Над интерфейсом мира нет.** Над хотбаром и над любой панелью HUD (статус, время, сводка
  инвентаря, таблица клавиш; строка подсказки у курсора не в счёт) нет призрака, а клики и
  удержания не уходят в мир: ни постановки, ни окна здания, ни добычи, ни скана, ни разбора.
  **R** над панелью тоже ничего не поворачивает.
- **Потраченное нажатие не становится удержанием.** Если нажатие кнопки мыши уже что-то сделало в
  интерфейсе (слот хотбара, окно, панель HUD) или в мире (постановка, окно здания), то до
  отпускания этой кнопки оно не превращается в удержание в мире: ПКМ, поставившая последний бур
  на залежь, не запускает скан этой залежи, а ЛКМ, нажатая на слоте хотбара и уведённая на карту,
  не копает.
- **Скан** — удержание ПКМ по залежи, только когда в слоте **не** постройка. С постройкой в слоте
  над залежью скан не запускается никогда (бур при этом ставится на залежь по `placeable_on`).
- **Призрак постройки** виден, когда в слоте постройка, курсор над картой (не над хотбаром и не над
  панелями HUD), окна закрыты: полупрозрачный силуэт настоящего здания, зелёный — можно, красный —
  нельзя (занято, вне 🔧 `BUILD_RANGE`, горы/вода, неподходящий тайл), тонкая рамка тайла поверх
  силуэта и слабое кольцо дальности вокруг дрона.
- **R** — поворот на 90° по часовой (клавиши T больше нет, R ничего не открывает):
  1. в слоте постройка с направлением (конвейер) — поворачивается призрак;
  2. в слоте постройка без направления (лампа, склад и др.) — **ничего**: призрак есть, поэтому
     и стоящий конвейер под курсором не крутится;
  3. слот пуст или в нём не постройка — поворачивается стоящий конвейер под курсором, иначе ничего.
- **Разбор** — удержание ЛКМ по своей постройке в радиусе `BUILD_RANGE` 🔧 `DISMANTLE_TIME = 0.7` с,
  над зданием кольцо прогресса. Отпустил раньше — прогресс сбрасывается, здание стоит. Готово —
  здание исчезает и **падает на землю предметом** (стак из 1), содержимое контейнеров высыпается
  вокруг; дрон подбирает всё обычным автоподбором.
- **E** открывает и закрывает окно инвентаря: слева сетка дрона и ряд хотбара под ней, справа
  панель крафта (`02_resources_recipes.md` § «Интерфейс»). Клавиш **I, Tab** и книги рецептов
  (**R**) больше нет.
- **Ввод текста.** Пока поле поиска в фокусе (`ui.text_input_active`): WASD не двигают дрона,
  цифры не выбирают слоты, E не закрывает окно, R не поворачивает, Пробел — это пробел в строке,
  F1–F4 и Q молчат. Backspace стирает символ, Enter снимает фокус, как и Esc.
  **Esc** сначала снимает фокус, второй Esc закрывает окно; клик вне поля тоже снимает фокус.
- **Пауза** работает и с открытым окном, и её видно: затемнение с надписью «ПАУЗА» рисуется
  поверх окна и хотбара. Пока окно открыто, добыча, скан и разбор не ведутся. На паузе картинка
  замирает (лента, лучи, частицы), но остаётся на экране.
- **Ремонт (M6):** удержание ЛКМ по **повреждённой** своей постройке чинит её (зелёный луч);
  целую — разбирает. Дочинил, не отпуская ЛКМ, — разбор не начнётся, пока кнопку не отпустить.
- **Esc и меню паузы (M6, просьба автора):** Esc снимает фокус поиска, закрывает окно, а без
  окон открывает **меню паузы** с кнопками «Продолжить» и «Выйти». Игра закрывается только кнопкой
  «Выйти» (или крестиком окна); повторный Esc закрывает меню. Работает и на экране поражения.
